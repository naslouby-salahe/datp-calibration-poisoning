## 1. Purpose
Define a typed CP2 config schema (pydantic/frozen dataclass) so all scientific
parameters come from config, not hardcoded constants.

## 2. Pre-start audit
Inspect:
```text
src/datp/config/{models,compose}.py   # existing config style
src/datp/attacks/poisoning_config.py   # legacy CalibrationPoisoningConfig
docs/DATP_CP_Roadmap.md §10, §12 (locks)
```

## 3. Scope
Typed config covering: `policy: ThresholdPolicy`, `objective: AttackerObjective`,
`source: PoisoningSourceStrategy`, `injection_rule: CalibrationInjectionRule`,
`knowledge: PoisoningKnowledge`, `target_scope: PoisoningTargetScope`,
`defense: PoisoningDefense`, `scale: ExperimentScale`, fractions, seeds
(`training_seed`, `poisoning_seed`, `analysis_seed`, `split_seed`,
`compromise_pattern_seed=400`), `n_min=100`, B4 params (`K=3`, `n_init=10`,
`max_iter=300`, `random_state=42`), tail mass (10%), materiality factor (0.1),
`mu_flag_threshold` (locked later). Validate ranges and reject E=5 at config level.

## 4. Non-goals
- No `shift_magnitude` field (non-protocol). Retire legacy config.
- No untyped dicts for core config; no unsafe defaults.

## 5. Scientific locks
Fractions `{0,0.10,0.20,0.40}` (MVP); SINGLE_CLIENT for MVP; victim-local
reservoirs; B3 not selectable in default policy; E=1.

## 6. Coding locks
Frozen/typed config; no hardcoded scientific values in modules; no `Any`; no silent
fallbacks that change scientific behavior.

## 7. Implementation guidance
Mirror existing `config/models.py` conventions. Provide validation in
`__post_init__`/validators.
