## 1. Purpose
Build the CP2 artifact-validation/provenance gate that enforces E=1, rejects E=5 and
journal-only artifacts, and confirms shared-score reuse before any run consumes
clean artifacts.

## 2. Pre-start audit
Inspect:
```text

docs/DATP_CP_Roadmap.md §7 (provenance), §14, §15
```

## 3. Scope
- Validator that checks: provenance manifest present; **E=1**; CP2-generated within
  this repository; DATP split semantics; per-client calibration scores present; clean
  test scores present; no journal-only variants; safe read-only paths. **Reject E=5.**
- Confirm clean and poisoned share training_seed/AE/split/test scores/victim plan.
- Raise explicit errors (no silent fallback) on violation.

## 4. Non-goals
- No retraining (FB1 owns that).
- No poisoning logic.

## 5. Scientific locks
E=1 only; reject E=5; shared score artifacts; poisoning is the only stochastic
difference between clean and poisoned.

## 6. Coding locks
Explicit errors for provenance/schema violations; typed; no swallowed exceptions; no
duplicated validation.

## 7. Implementation guidance
Extend inherited validation patterns; integrate the CP2 manifest model from
CP2-T019.
