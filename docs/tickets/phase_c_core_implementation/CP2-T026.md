## 1. Purpose
Implement victim-local reservoir construction for the three source strategies,
following the source-precedence rule, with no cross-client/test/training leakage.

## 2. Pre-start audit
Inspect CP2-T008 split/source findings and `docs/DATP_CP_Roadmap.md` §6

## 3. Scope
- Build reservoirs per precedence: (1) victim-local benign calibration-*candidate*
  scores if exposed; else (2) resample-with-replacement from the victim's own clean
  calibration distribution — full pool (RANDOM), upper 10% tail (HIGH), lower 10%
  tail (LOW).
- Detect degenerate tails (<2 distinct values) → mark INFEASIBLE (FB2 path).
- Record reservoir mode for the manifest.

## 4. Non-goals
- **Test scores are never a reservoir. Training scores are not a reservoir.**
- No cross-client reservoirs in the main matrix (diagnostic-only).

## 5. Scientific locks
Victim-local only; fixed 10% tail mass; with-replacement resampling; reservoir mode
recorded; INFEASIBLE handling per FB2.

## 6. Coding locks
Typed; no in-place mutation of clean arrays; no leakage from test/training; no
hardcoded tail mass (from config).

## 7. Implementation guidance

Use the SeedSequence child generator.
