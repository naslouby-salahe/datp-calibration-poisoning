calibration scores, reusing inherited thresholding strategies.

## 3. Scope
- Compute `τ_clean` and `τ_pois` for B1 and B2 on the same victim/eligible set.
- B1: poisoning a victim shifts the global quantile input; B2: only the victim's own
  threshold changes.
- No score recomputation; consume saved/synthetic scores.

## 4. Non-goals
- No metric aggregation (CP2-T033).
- No B4 (CP2-T031).

## 5. Scientific locks
Reuse DATP thresholding; eligible-only aggregation; Calibration-Pending→`tau_global`;
quantile `q` from config; no recompute of scores.

## 6. Coding locks
Reuse strategies, do not duplicate; typed; no hardcoded `q`.

## 7. Implementation guidance
Thin CP2 adapter calling inherited B1/B2 strategies on clean and poisoned inputs.
