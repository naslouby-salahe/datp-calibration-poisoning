## 1. Purpose
Recompute B4 (fingerprint-cluster) thresholds under poisoning and decompose each
victim's threshold change into aggregation and cluster-churn components, using
**client-indexed effective thresholds** (never raw cluster labels).

## 2. Pre-start audit
Inspect CP2-T011 B4 reproduction findings; `docs/DATP_CP_Roadmap.md` §5 (B4), §8
(Δτ decomposition).

## 3. Scope
- B4 N-BaIoT: K=3, k-means++, `n_init=10`, `max_iter=300`, `random_state=42`,
  fingerprint `[mean, std, skew, p95]`.
- Compare each victim's **effective threshold** before/after; decompose
  `Δτ_total = Δτ_agg + Δτ_churn` (churn = effect of cluster reassignment vs
  within-cluster aggregation change).
- Track by client id; never compare raw cluster labels across clean/poison.

## 4. Non-goals
- No K sweep here (FB4 only, gated).
- No raw-label comparison.

## 5. Scientific locks
B4 hyperparameters locked; client-indexed effective thresholds; `Δτ_total=Δτ_agg+
Δτ_churn`; cluster labels are not stable identifiers.

## 6. Coding locks
Deterministic clustering (`random_state=42`); typed; no hardcoded fingerprint set
(from constants); no raw-label comparison.

## 7. Implementation guidance
Compute clusters clean and poisoned; map by client id; compute effective thresholds
and the two-term decomposition.
