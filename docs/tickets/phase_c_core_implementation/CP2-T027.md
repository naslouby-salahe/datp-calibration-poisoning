## 1. Purpose
Implement the protocol-faithful calibration injector that **replaces** a fixed
budget of positions with values resampled with replacement from the victim-local
reservoir, holding cardinality constant. This replaces the legacy `shift_magnitude`
prototype.

## 2. Pre-start audit
Inspect CP2-T010 disposition table; `docs/DATP_CP_Roadmap.md` §6 (injection); the
legacy `src/datp/attacks/calibration_poisoning.py`.

## 3. Scope
- For victim `i`, fraction `f>0`: `m_i = max(1, round(f·n_i))`; replace `m_i`
  randomly chosen positions with values **resampled with replacement** from the
  reservoir; total size stays `n_i`.
- `f=0` → returns an exact copy (zero change).
- Operate on a **copy**; never mutate clean arrays in place.
- Use the SeedSequence child generator (`[training_seed, poisoning_seed, client_id,
  scope_id]`).

## 4. Non-goals
- No value shifting/adding (retire `shift_magnitude`).
- No change to cardinality; no in-place mutation.

## 5. Scientific locks
`REPLACE_FIXED_BUDGET`; fixed-size with-replacement replacement; no in-place
mutation; deterministic child seeds; objectives map to source/tail selection.

## 6. Coding locks
No backward compatibility (replace prototype); typed; no hardcoded science; pure
function; no `Any`.

## 7. Implementation guidance
New injector function/module under `attacks/`. Remove the legacy
`poison_calibration_errors` once references are migrated; update/replace its tests.
