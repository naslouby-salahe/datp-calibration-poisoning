## 1. Purpose
Provide deterministic synthetic per-client benign calibration/test score arrays so
the entire CP2 pipeline can be smoke-tested CPU-only without real data.

## 2. Pre-start audit
Inspect:
```text
tests/fixtures/payloads.py  tests/unit/conftest.py

docs/DATP_CP_Roadmap.md §10 (smoke), §16 compute/tests
```

## 3. Scope
- Synthetic generators producing eligible and Calibration-Pending clients, with
  distinct cal/test_benign/test_attack arrays and the canonical `reconstruction_error`
  column.
- Deterministic via the SeedSequence helper; CPU-only; no CUDA requirement.
- Include degenerate cases (tiny tail) for FB2 testing.

## 4. Non-goals
- No real N-BaIoT loading (that is Phase E).
- No poisoning logic.

## 5. Scientific locks
`n_min=100` eligibility boundary representable; benign-only calibration; scores
shared across policies; deterministic.

## 6. Coding locks
Typed fixtures; centralized via testsupport; no hardcoded magic; CPU-safe; no CUDA.

## 7. Implementation guidance
Place reusable builders in `src/datp/testsupport/` (or `tests/fixtures/`) so unit +
smoke tests share them.
