policy-differentiated vulnerability (the CP2 paper's core narrative).

## 3. Scope
- **ASR:** fraction of victim/cell instances whose `|Δτ|` exceeds the per-client
  significance scale `δ_τ,i` in the intended direction.
- **Blast radius:** number of clients with non-trivial threshold change per single
  victim (B1 fleet-wide; B2 victim-local; B4 cluster-local).
- **Spillover:** co-cluster (B4) and global (B1) effects on non-victims; framed as a
  mechanism, not an independence violation.

## 4. Non-goals
- No statistical inference (CP2-T035).

## 5. Scientific locks
ASR uses `δ_τ,i`; blast radius reflects policy locality (B1 global / B2 local / B4
cluster); spillover is mechanistic.
