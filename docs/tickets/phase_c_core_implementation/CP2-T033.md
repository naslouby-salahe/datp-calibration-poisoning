## 3. Scope
- `Δτ = τ_pois − τ_clean`; `Δτ_rel = Δτ / max(|τ_clean|, ε)`.
- Per-client significance scale `δ_τ,i = 0.1 · IQR(clean cal scores_i)`.
- `CV(FPR) = σ/µ` (**no ε**); always report **coverage ratio**.
- Guard metrics: `IQR(FPR)`, `max−min FPR`, worst-client FPR.
- `mu_flag_threshold = round(M_clean/8, 2 s.f.)` **locked before poisoned runs**.
- AUROC computed as an invariant (calibration-only attack must not move ranking).

## 4. Non-goals
- No paired stats/bootstrap (CP2-T035).
- No score recomputation.

## 5. Scientific locks
CV(FPR) no ε; coverage always reported; `δ_τ,i` per-client; `mu_flag_threshold`
locked pre-poison; AUROC invariant; reuse inherited statistics (cv, bootstrap later).

## 6. Coding locks

scores; no `Any`.
