# CP2-T000 — Ticket System Bootstrap

**Phase:** 00 — Setup
**Type:** audit
**Priority:** critical
**Status:** not started
**Dependencies:** none
**Blocks:** CP2-T001
**Expected test level:** static
**Graphify required:** conditional

## 1. Purpose
Establish the CP2 ticket system, tracking folders, and conventions so future
agents can resume work deterministically. This ticket records that the scaffold
exists and is internally consistent.

## 2. Pre-start audit
Inspect the actual repository before changing anything. Do not trust progress
files alone. Confirm these exist and are coherent:
```text
docs/tickets/README.md
docs/tickets/TICKET_INDEX.md
docs/tickets/_ai_tracking/{progress,audits,diagnostics,decisions,manifests,run_logs,paper_notes,graphify}/
docs/DATP_CP_Roadmap.md
```
Write any discrepancy under `docs/tickets/_ai_tracking/audits/`.

## 3. Scope
- Verify the phase folders `phase_00_setup … phase_g_experiment_and_paper` exist.
- Verify all tracking files referenced by the index exist.
- Confirm ticket IDs in `TICKET_INDEX.md` are unique and the last three are
  experiment / analysis / paper.

## 4. Non-goals
- No production code changes.
- No ticket content edits beyond fixing broken links/IDs.
- No experiment or artifact work.

## 5. Scientific locks
CP2 is calibration-channel poisoning only. No journal scope. Default policies
`{B1_GLOBAL, B2_PERSONALIZED, B4_CLUSTER}`; **B3 not in the default enum**. These
locks are repeated in every downstream ticket.

## 6. Coding locks
No backward compatibility by default; use enums; centralize constants; typed
config models; no hardcoded scientific values; no `Any` unless justified; no AI
comments; no TODO placeholders; no `type: ignore` unless tracked; no duplicated
implementations; no stale journal logic; no in-place mutation of clean arrays.

## 7. Implementation guidance
Docs only. Touch files under `docs/tickets/**`. Discover the real tree first with
`list_dir`/`file_search`.

## 8. Tests and diagnostics
```text
# structural only
ls -R docs/tickets | head -100
```
No pytest needed unless a script is added.

## 9. Graphify
Not applicable to docs-only scaffolding. Record deferral in
`docs/tickets/_ai_tracking/graphify/CP2_GRAPHIFY_STATUS.md`.

## 10. Paper-writing notes
None.

## 11. Acceptance criteria
- All phase folders and tracking folders exist.
- README and index are consistent; IDs unique; final three correct.
- Any discrepancy recorded as an audit note.

## 12. Blocking conditions
