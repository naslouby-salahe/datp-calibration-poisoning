ticket workflow, the no-backward-compatibility rule, the Graphify rule, the test
taxonomy, and the paper-notes requirement — without breaking useful automation.

## 3. Scope
- Add a concise CP2 alignment block (locks, ticket workflow under `docs/tickets/`,
  no-backward-compat, Graphify rule, test taxonomy, paper-notes requirement) to the
  relevant agent/skill/instruction files **only where it does not break them**.
- Remove or clearly mark obsolete journal-only instructions that are unsafe for CP2.
- If a change is risky/uncertain, write an audit note + create no change (defer to a
  follow-up). Do not guess.

## 4. Non-goals

- Do not add CI that runs experiments.
