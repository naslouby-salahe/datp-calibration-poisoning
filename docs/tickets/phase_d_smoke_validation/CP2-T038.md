## 3. Scope
Harness runs clean→inject→threshold(B1/B2/B4)→metrics→diagnostics→inference on
synthetic fixtures, asserting:
1. `f=0` reproduces clean exactly (zero Δτ).
2. Cardinality preserved after injection (`n_i` constant).
3. Clean arrays never mutated in place.
4. HIGH raises, LOW lowers the threshold (direction correct).
5. Calibration-Pending excluded from victims/CV(FPR), gets `tau_global`.
6. Determinism: same seeds → identical outputs.
