# BLOCKERS.md — Blocker Log

Record all blockers here. A blocker prevents a task from proceeding.

---

## Blocker Format

```
## BLK-<ID>
- Blocker ID: BLK-<ID>
- Task ID: <task being blocked>
- Severity: LOW | MEDIUM | HIGH | CRITICAL
- Description: <what is blocking the task>
- Affected files: <list or NONE>
- Scientific risk: <risk to CP2 protocol if unresolved, or NONE>
- Engineering risk: <risk to code correctness or type safety, or NONE>
- Required decision: <what needs to be decided to unblock>
- Owner: <agent or human responsible for resolution>
- Status: OPEN | RESOLVED | DEFERRED
- Resolved by: <DEC-ID or summary of resolution, or N/A>
```
